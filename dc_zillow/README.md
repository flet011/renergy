# DCZillow — AI Infrastructure Intelligence Platform

> **"The Zillow for Data Centers"** — A role-based decision engine for the $500B AI infrastructure market, backed by 17 OSINT databases and real-time actionable insights.

---

## Overview

DCZillow is a React web application that transforms the 17 OSINT-sourced databases compiled in [PKP_renergy](../README.md) into an interactive intelligence platform. It goes beyond data display — it synthesizes raw market data into **actionable decisions** tailored to three distinct user roles.

### What It Does

- **Operator (Supply Side)**: Maximize revenue, optimize pricing, outmaneuver competitors across your portfolio
- **Buyer (Demand Side)**: Find capacity, reduce costs, deploy faster with smart recommendations
- **Investor (Capital)**: Discover deal flow, assess risk, capture alpha with composite scoring
- **Explore** 43+ data center facilities across 18 global markets with interactive tooltips
- **Compare** GPU cloud pricing across 10 models (NVIDIA B200/H200/H100/A100, AMD MI300X/MI325X)
- **Analyze** market intelligence: vacancy rates, power costs, growth trends, construction pipeline
- **Track** $181B+ in hyperscaler CapEx and 11.4 GW of new capacity under construction

## AI Intelligence Layer

Each role receives a curated set of **actionable insights** generated by the intelligence engine (`src/data/insights.js`). Insights are categorized by:

- **Urgency**: Critical / High / Medium
- **Type**: Threat / Opportunity / Action / Warning / Savings

### Operator Intelligence
- Portfolio performance analysis (utilization, vacancy trends)
- Competitive benchmarking against 10 major operators
- Market pricing power signals
- Expansion opportunity scoring

### Buyer Intelligence
- Smart capacity recommendations ranked by fit score
- TCO comparison across markets (cost optimization)
- GPU performance/value advisor
- Power queue and supply constraint alerts

### Investor Intelligence
- Composite investment attractiveness scoring (Growth 30% + Supply Tightness 25% + Power Cost 20% + Scale 15% + ESG 10%)
- Operator valuation scorecard (Efficiency 40% + Scale 25% + Sustainability 20% + Diversification 15%)
- Investment signals: Strong Buy / Buy / Hold / Watch
- Pipeline ROI analysis

## Interactive Features

### Glossary Tooltips
Every metric across the platform has a hover tooltip explaining what it means. 40+ metric definitions covering:
- **Power**: MW, GW, kW, kW/mo, available MW, total capacity
- **Efficiency**: PUE, utilization, vacancy rate
- **Infrastructure**: Liquid cooling, DGX-ready, bandwidth, racks, sqft
- **Market**: Average rent, power cost, power queue, YoY growth, construction pipeline, tier
- **GPU**: TFLOPS, memory, memory type, TDP, MSRP, lead weeks, cloud pricing
- **Financial**: Revenue, market cap, revenue per MW, CapEx, TCO, investment score

Tooltips always appear **above** the trigger element and feature a consistent square help icon indicator.

### Contact Forms (CTA)
Three functional form types on facility detail pages:
- **Request Quote** — Company, contact, capacity needs, requirements
- **Schedule Tour** — Company, contact, preferred date, notes
- **Contact Operator** — Company, contact, subject, message

### Deep-Dive Links
Every card includes "Dig Deeper" / "Research This Insight" links that open real-time web searches for the relevant topic — operators, markets, GPU benchmarks, project news.

### Background Imagery
- **Login screen**: Modern glass building exterior (Unsplash) with gradient overlay
- **Facility detail**: Data center server room hero banner

## Design

Dark-mode theme optimized for data-dense dashboards:

- **Background**: `#0a0e17` (deep navy)
- **Accent**: `#3b82f6` (blue)
- **Available/Good**: `#10b981` (green)
- **Warning/Tight**: `#f59e0b` (amber)
- **Critical/Limited**: `#ef4444` (red)
- **Tooltip**: `#111827` solid background, `#60a5fa` term, `#d1d5db` definition

### Tooltip System
- 16x16px square help icon with blue-tinted background
- Fixed-position popup always rendered above the trigger element
- `useLayoutEffect` measures actual popup dimensions before positioning
- Fallback below only when < 4px from viewport top
- Solid opaque background for legibility on any page

## Relationship to PKP_renergy

This application lives within the `PKP_renergy` project as `dc_zillow/`. It is the **intelligence platform frontend** that consumes PKP_renergy's curated OSINT data and presents it as a role-based decision engine. The data flow is:

```
PKP_renergy/data/ (17 OSINT databases, CSV/MD)
        ↓  curated & embedded into
dc_zillow/src/data/ (facilities.js, markets.js, insights.js, glossary.js)
        ↓  synthesized by
dc_zillow/src/data/insights.js (intelligence engine — generates actionable insights)
        ↓  rendered by
dc_zillow/src/components/ (React UI — role-based dashboards, tooltips, modals)
```
